Разбор кода: Процесс Рождения-Гибели

Этот документ представляет собой подробный разбор скрипта на языке Python, моделирующего процесс рождения и гибели (ПРГ) — один из фундаментальных классов марковских процессов в Теории Массового Обслуживания (ТМО).

Цель программы: найти стационарное распределение вероятностей p_i (долю времени, которую система проводит в состоянии с i заявками) тремя разными методами и сравнить их результаты.

1. Инициализация класса и параметров

class BirthDeathProcess:
    def __init__(self, lam, delta, eps, N, M, K):
        self.lam = lam
        self.delta = delta
        self.eps = eps
        self.N = N
        self.M = M
        self.K = K
        self.n_states = K + 1
        
        # Сразу строим матрицу
        self.A = self.build_matrix()

Объяснение кода:

Конструктор класса принимает параметры системы. Сохраняются интенсивность поступления (lam), коэффициенты обслуживания (delta, eps) и границы смены режимов обслуживания (N, M, K). Переменная n_states равна K + 1, так как состояния нумеруются от 0 до K включительно. Сразу при создании объекта вызывается метод build_matrix().

⚙️ Разбор функций Python
  • class: Создает структуру (класс). Класс объединяет параметры системы и функции для их обработки.
  • __init__(self, ...): Метод-конструктор, который вызывается автоматически при создании объекта.
  • self: Ссылка на сам объект. Позволяет сохранять переменные (например, self.lam = lam) так, чтобы они были доступны во всех остальных функциях этого класса.
📚 Теория ТМО: Постановка задачи

Мы рассматриваем Систему Массового Обслуживания (СМО) с ограниченной вместимостью K. Состояние системы i — это количество заявок в системе.

  • Интенсивность входного потока (рождение) постоянна: λi = λ. В ТМО это означает простейший (пуассоновский) поток заявок.
  • Интенсивность обслуживания (гибель) μi зависит от текущего состояния. Это типично для систем, где при увеличении очереди подключаются новые каналы обслуживания или меняется скорость работы (в нашем случае меняется коэффициент с δ на ε и обратно).

2. Построение матрицы интенсивностей переходов

    def build_matrix(self):
        A = np.zeros((self.n_states, self.n_states))
        for i in range(self.n_states):
            # Гибель (шаг влево)
            if i > 0:
                if i <= self.N: mu = i * self.delta
                elif i <= self.M: mu = i * self.eps
                else: mu = i * self.delta
                A[i, i - 1] = mu
            
            # Рождение (шаг вправо)
            if i < self.K:
                A[i, i + 1] = self.lam

            # Диагональ
            A[i, i] = -np.sum(A[i, :])
            
        return A

Объяснение кода:

Метод создает квадратную матрицу A. Цикл проходит по всем состояниям от 0 до K.

  • A[i, i - 1] (под главной диагональю): интенсивность ухода в предыдущее состояние.
  • A[i, i + 1] (над главной диагональю): интенсивность перехода в следующее состояние, всегда равна lam.
  • A[i, i] (главная диагональ): сумма всех остальных элементов строки с отрицательным знаком.
⚙️ Разбор функций NumPy
  • np.zeros((строки, столбцы)): Быстро создает матрицу нужного размера, заполненную нулями.
  • A[i, :]: Синтаксис срезов. Означает "взять всю строку i (все её столбцы)".
  • np.sum(...): Вычисляет сумму элементов переданного массива. В данном случае мы суммируем все интенсивности выходов из состояния.
📚 Теория ТМО: Инфинитезимальная матрица переходов

В непрерывном времени марковская цепь описывается не вероятностями переходов, а интенсивностями (матрицей инфинитезимальных характеристик A или Q).

Фундаментальное свойство такой матрицы: сумма элементов в каждой строке равна нулю (Σj aij = 0). Именно поэтому диагональный элемент всегда отрицателен и равен по модулю сумме интенсивностей выходов из состояния i.

3. Аналитический расчет (Рекуррентный метод)

    def solve_recursive(self):
        p = np.zeros(self.n_states)
        p[0] = 1.0  # Ненормированная вероятность
        
        for i in range(1, self.n_states):
            if i <= self.N: mu = i * self.delta
            elif i <= self.M: mu = i * self.eps
            else: mu = i * self.delta
                
            p[i] = p[i - 1] * (self.lam / mu)
            
        return p / np.sum(p)  # Условие нормировки

Объяснение кода:

Мы задаем стартовый "вес" p[0] = 1.0. Затем в цикле каждое следующее состояние вычисляется через предыдущее путем умножения на отношение интенсивностей lam / mu. В конце весь массив нормируется.

⚙️ Разбор функций NumPy
  • p / np.sum(p): Демонстрация векторизованных операций (broadcasting). Мы делим весь массив p на число (сумму всех элементов). NumPy применяет это деление к каждому элементу массива автоматически, без использования медленных циклов.
📚 Теория ТМО: Уравнения детального равновесия (Локальный баланс)

Для марковских цепей в виде прямой линии (0 ↔ 1 ↔ 2 ↔ ... ↔ K) действует правило: в стационарном режиме поток вероятности из i-1 в i в точности равен возвратному потоку из i в i-1. Математически: pi-1 · λ = pi · μi.

Отсюда выводится рекуррентная формула: pi = pi-1 · (λ / μi).

Вместо того чтобы разворачивать эту формулу в огромные степени и факториалы (что приводит к переполнению памяти), мы применяем метод весов: считаем вес p0 = 1, вычисляем остальные веса по цепочке, а затем делим каждый вес на их общую сумму. Это гарантирует выполнение условия нормировки (Σ pi = 1).

4. Численные матричные методы

    def solve_matrix(self):
        vals, vecs = eig(self.A.T)
        idx = np.argmin(np.abs(vals))
        p = np.real(vecs[:, idx])
        p = np.abs(p) 
        return p / np.sum(p)

    def solve_nullspace(self):
        ns = null_space(self.A.T)
        p = np.abs(ns[:, 0])
        return p / np.sum(p)

Объяснение кода:

Оба метода решают систему линейных алгебраических уравнений (СЛАУ), но разными алгоритмами линейной алгебры.

⚙️ Разбор функций SciPy и NumPy
  • self.A.T: Транспонирует матрицу (меняет строки и столбцы местами).
  • eig(...): Находит собственные значения и векторы матрицы. Возвращает кортеж (значения, векторы).
  • np.abs(...): Модуль числа (для комплексных чисел — расстояние на комплексной плоскости). Избавляет нас от отрицательных знаков.
  • np.argmin(...): Находит минимальное значение в массиве и возвращает его индекс. Мы ищем собственное значение, ближайшее к 0.
  • np.real(...): Отбрасывает мнимую часть комплексного числа (возникающую из-за микро-погрешностей процессора).
  • null_space(...): Находит базис нуль-пространства (ядра) матрицы через сингулярное разложение (SVD).
📚 Теория ТМО: Система уравнений Колмогорова (Глобальный баланс)

Если система сложнее прямой линии, детальное равновесие не работает. Используется уравнение глобального баланса: суммарный поток вероятностей во все состояния равен суммарному потоку из всех состояний. В векторном виде это выглядит как: π · A = 0, где π — вектор-строка вероятностей.

Чтобы решить это стандартными библиотеками, уравнение транспонируют: AT · πT = 0 · πT. Математически это означает две вещи:

  1. Вектор πT является собственным вектором матрицы AT для собственного значения λeig = 0. (Это реализует метод eig).
  2. Вектор πT лежит в ядре (нуль-пространстве) матрицы AT, так как при умножении на неё дает ноль. Так как наша цепь эргодична, базис этого пространства состоит ровно из одного вектора. (Это реализует метод null_space).

⚙️ Форматирование и Matplotlib
  • f"{значение:.6f}": Вывод числа (float) строго с 6 знаками после запятой.
  • f"{diff:.2e}": Вывод в научном формате. Разница будет выведена компактно (например, 1.23e-16).
  • plt.subplot(rows, cols, index): Разделяет окно графика. (2, 1, 1) — сетка 2х1, рисуем в первой (верхней) ячейке.
  • plt.bar(x, height, width): Столбчатая диаграмма. Сдвиги x - 0.2 и x + 0.2 не дают столбцам наложиться друг на друга.
📚 Теория ТМО: Показатели эффективности СМО

Стационарные вероятности pi — фундамент для расчета реальных метрик системы:

  • Вероятность простоя: p0 (система пуста).
  • Вероятность отказа: pK (очередь переполнена, новые заявки теряются).
  • Пропускная способность: Q = 1 - pK.
  • Среднее число заявок: L = Σ (i · pi) (математическое ожидание длины очереди).

Заключение

Рекуррентный метод является наиболее точным для процессов рождения-гибели, так как он аналитический (работает через свойства графа состояний). Матричные методы являются универсальными (подходят для расчёта любых сложных сетей с нетривиальными переходами), но решаются численно и имеют незначительную ошибку машинного округления.
